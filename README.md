# 🌸 Flower Bloom Store — Enterprise-Level ASP.NET Core MVC E-Commerce Platform

**Flower Bloom Store** is a full-stack e-commerce web application developed using **ASP.NET Core MVC** and designed with a professional **Clean Architecture** approach to simulate real-world enterprise software development.

The platform enables customers to explore flower collections, place customized orders, and schedule deliveries, while providing administrators with powerful management and monitoring capabilities.

This project focuses not only on building features, but on applying **industry-standard architecture, team collaboration workflows, and scalable backend design principles**.

---

* Separation of concerns

---

## 🏗 Architecture Overview

The solution follows a **multi-layered architecture** inspired by Clean Architecture principles:

* **Web Layer**

  * ASP.NET Core MVC
  * Controllers, Razor Views, ViewModels
  * Authentication & Authorization

* **Application Layer**

  * Business logic & use cases
  * Service abstractions
  * DTOs and validation

* **Domain Layer**

  * Core entities
  * Business rules
  * Enums & contracts

* **Infrastructure Layer**

  * Entity Framework Core
  * Repository implementations
  * Database integration
  * ASP.NET Identity configuration

This separation ensures scalability, flexibility, and long-term maintainability.
